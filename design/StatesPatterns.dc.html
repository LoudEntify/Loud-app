Every screen has five states

The designs elsewhere show the happy path. These are the other four, built once as shared parts so every screen behaves the same way. Use these rather than inventing a new empty screen each time.

Loading

Grey shapes in the layout the real content will take, so nothing jumps when it arrives. No spinners on full screens.

After 10 seconds with nothing back, switch to the error state.

Empty

Say plainly what is not here, then give the one action that fills it. Never a blank screen, never a sad face.

Nothing live right now Three shows start later today. See what's coming

Error

Say what failed in plain words, and give a way forward. No codes, no apology paragraphs, never "something went wrong".

Offline

A bar across the top, not a screen that blocks everything. Anything already loaded stays readable, and it clears itself when the connection returns.

Where each one bites hardest

Discover, nothing live. Show what starts later, never a blank feed. A new artist's profile. No shows yet, so show the setup progress instead. Search with no results. Offer near spellings and the closest genre. An empty inbox. Suggest following someone. A wallet at zero. Explain what tokens do before asking them to buy any. A show that drops mid-stream. Hold the viewer in the room and keep trying.
